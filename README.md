# Slow Horizon

A relaxed, endless road-trip driving game in the browser. Drive through meadows, coast, desert, forest, mountains and snow, stop in villages, take postcards in photo mode, or take the racing car to the circuit.

Loosely inspired by [Slow Roads](https://slowroads.io).

## Play

Open `index.html` in a browser.
